\section*{Conclusion}
The same-support and different-pair opposite-sign classes pass the familywise
criterion, while the conjugate partner preserves the exact-null control. The
different-pair same-sign class has the predicted intermediate effect size but does
not pass the four-test threshold at this budget. This is a power boundary outcome,
not an observed zero: its finite-shot contrast and $\chi^2_3$ are consistent with
the pre-execution exact noncentrality estimate.

\section*{Integrity and next step}
All four raw count tables satisfy joint-all-zero count $\leq$ clock-acceptance count.
The same-sign row needs an independent higher-budget replication before it can be
called finite-shot detected. That replication is a new one-test experiment and must
not be pooled into this four-test family.
